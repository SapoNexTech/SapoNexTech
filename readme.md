### 👋 About Me

I'm **Ankit Yadav**, a developer interested in building useful web experiences and Android apps while steadily learning cybersecurity. I enjoy exploring how applications work, how systems communicate, and how security weaknesses can be identified and fixed responsibly.

- 🌐 Building responsive websites and learning modern web development
- 📱 Exploring Android app development with Kotlin & Java
- 🔐 Learning ethical hacking, web application security, and system security
- 🕵️ Exploring **OSINT** — Open-Source Intelligence using publicly available information
- 🌐 Practising networking concepts and security fundamentals
- 🗄️ Working with SQL concepts and exploring Supabase and Firebase
- 🎯 **Current focus:** Web Development · Android · Cybersecurity · Networking · Software Engineering

> *Always learning. Always building. Security testing only on systems I own or have permission to assess.*
